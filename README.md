## AMERICAN SALES ANALYSIS
## DESCRIPTION ##
A American Sales Analysis Project Exploring Sales Performance,Customers,Products,Regions,Stores,and Sales Teams.
**PROJECT OVERVIEW**

**Objective**
To analyse sales data and identify trends, customer behaviour, product performance, and areas for improvement.

**Scope**

* Sales and orders
* Products and categories
* Customers
* Regions and stores
* Sales team performance

Tools Used

* MySQL
* Power BI
* Excel
* DAX
* Power Query

Methodology

* Data collection
* Data cleaning
* SQL analysis
* Data visualization
* Dashboard development
